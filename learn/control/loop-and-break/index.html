loop and break

Programs often repeat work. The simplest way is loop, which repeats its block forever, until you stop it with break:

fn main() {
    let mut countdown = 3;
    loop {
        println!("{countdown}");
        countdown -= 1;
        if countdown == 0 {
            break;
        }
    }
    println!("Go!");
}

3
2
1
Go!

Each run through the block is an iteration. break exits the loop immediately, and the program continues after the loop's closing brace.

Getting a value out of a loop

loop is an expression too: break value ends the loop and makes value the result of the whole loop. That's perfect for "keep trying until something happens, then tell me the answer":

fn main() {
    let mut n = 1;
    let first_big_square = loop {
        if n * n > 500 {
            break n * n;
        }
        n += 1;
    };
    println!("first square above 500: {first_big_square} ({n} x {n})");
}

first square above 500: 529 (23 x 23)

When a loop is the final expression of a function, break value gives the function its return value. Inside a function, return also leaves a loop (and the whole function) immediately.

Infinite loops

If no break is ever reached, the loop runs forever and the program hangs. On this site, a run is stopped after 2 seconds ("time limit exceeded"); on your computer, press Ctrl+C. Some programs loop forever on purpose: a game's main loop or a server waiting for requests runs until it's told to quit.

Common mistakes

  • Never changing what the exit condition depends on: if countdown -= 1 is missing, countdown == 0 never becomes true and the loop never ends.
  • break value in other loops: only loop can return a value. The while and for loops coming next might run zero times, so they'd have no value to give (error[E0571]: `break` with value from a `while` loop).
  • Forgetting the ; after let x = loop { ... };.
