Looping: &v, &mut v and v

There are three ways to loop over a vector, and they match the three ways to use any value in Rust: borrow it, borrow it mutably, or take ownership.

fn main() {
    let mut prices: Vec<u32> = vec![1200, 450, 999];

    let mut total = 0;
    for p in &prices {
        total += *p;
    }
    println!("total {total}");

    for p in &mut prices {
        *p = *p * 9 / 10;
    }
    println!("{:?}", prices);

    for p in prices {
        println!("{p}");
    }
}

for p in &prices &u32, a shared reference unchanged, still usable
for p in &mut prices &mut u32, a mutable reference changed in place, still usable
for p in prices u32, the value itself moved: gone after the loop
  • In the first loop p is a reference, so *p reads the number it points to.
  • In the second loop *p = ... writes through the mutable reference into the vector itself (the borrowing module's *).
  • The third loop consumes the vector. Use it when you're done with the vector and want to move its elements somewhere else.

You'll also see the method forms prices.iter(), prices.iter_mut() and prices.into_iter(); they mean exactly the same three things.

When you need the position too

.iter().enumerate() gives you (index, element) pairs, which a for pattern takes apart:

fn main() {
    let runners = vec!["Ana", "Bo", "Cy"];
    for (i, name) in runners.iter().enumerate() {
        println!("{}. {name}", i + 1);
    }
}

1. Ana
2. Bo
3. Cy

That's tidier than for i in 0..runners.len() with runners[i], and clippy suggests it (needless_range_loop). Module 27 covers enumerate and friends properly.

Common mistakes

  • Using the vector after a consuming loop:

    fn main() {
    let v = vec![1, 2, 3];
    for x in v {
        println!("{x}");
    }
    println!("{}", v.len());
}

    error[E0382]: borrow of moved value: `v`

    Loop over &v if you still need v afterwards.

  • Changing the vector while looping over it. The loop holds a borrow of v; push needs a mutable borrow at the same time:

    fn main() {
    let mut v = vec![1, 2, 3];
    for x in &v {
        if *x == 2 {
            v.push(20);
        }
    }
}

    error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable

    This isn't fussiness: push might move the whole buffer to a bigger allocation, and the loop's reference would point at freed memory. In C++ this is a classic crash (iterator invalidation); in Rust it doesn't compile. Collect what you want to add in a second vector and add it after the loop.

  • Forgetting the *: x += 1 where x: &mut i32 fails with binary assignment operation `+=` cannot be applied to type `&mut i32` . Write *x += 1.
