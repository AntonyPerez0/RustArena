Implementing Display

{} in println! and format! works with any type that implements the standard trait std::fmt::Display. Numbers and strings implement it; your types don't, until you write it. You met this briefly for error types; here's the full picture.

use std::fmt;

struct Money {
    cents: i64,
}

impl fmt::Display for Money {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let sign = if self.cents < 0 { "-" } else { "" };
        let abs = self.cents.abs();
        write!(f, "{}${}.{:02}", sign, abs / 100, abs % 100)
    }
}

fn main() {
    let price = Money { cents: 1205 };
    let refund = Money { cents: -350 };
    println!("Price: {price}");
    println!("Refund: {}", refund);
    let text = price.to_string();
    println!("{} characters", text.len());
}

Price: $12.05
Refund: -$3.50
6 characters

Piece by piece:

  • use std::fmt; lets you write fmt::Display, fmt::Formatter and fmt::Result instead of the full paths.
  • The one required method is fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result. Copy that signature; you'll write it many times. (Docs and editors often show Formatter<'_>; the '_ is a lifetime, the topic of a later module, and you may leave it out.)
  • f is where the text goes. write!(f, ...) works like format! but writes into f, and it returns the fmt::Result you need, so it's the last expression (no semicolon).
  • Implementing Display also gives you .to_string() for free: the standard library implements ToString for every type that implements Display.

Display or Debug?

Debug ({:?}) is for developers: derive it on almost every type and get a faithful dump of the fields. Display ({}) is for users: you choose the exact format, so it can't be derived. Should Money show $12.05, 12.05 USD or 12,05 €? Only you know.

Several lines? Use writeln!(f, ...)?; for each line except the last, then end with write!. The ? passes a formatting error on, like you did with Result in the errors module.

Common mistakes

  • A semicolon after the last write!. The method then returns () instead of fmt::Result:
use std::fmt;

struct Tag(String);

impl fmt::Display for Tag {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "#{}", self.0);
    }
}

fn main() {
    println!("{}", Tag(String::from("rust")));
}

error[E0308]: mismatched types
  • println! inside fmt. It prints straight to the screen instead of into the result, so format!("{}", x) and x.to_string() get an empty string. Always write into f.
  • write!(f, "{}", self) inside Display for the same type. That calls fmt again, forever, until the program crashes with a stack overflow. Format the fields, not self.
  • Using {} on a type without Display gives error[E0277]: `Money` doesn't implement `std::fmt::Display` . The compiler suggests {:?}, which is fine for debugging but not for output users read.

Challenge 3

Playing cards. Implement Display for both types:

  • Suit shows as ♠, ♥, ♦ or ♣.
