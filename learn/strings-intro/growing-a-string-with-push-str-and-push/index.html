Growing a String with push_str and push

A String can grow. Two methods add text at the end:

fn main() {
    let mut log = String::new();
    log.push_str("user=ferris");
    log.push(';');
    log.push_str(" action=login");
    println!("{log}");
}

user=ferris; action=login
  • push_str(text) appends a &str, any amount of text.
  • push(c) appends a single char, written in single quotes.
  • Both change the String, so it must be declared let mut.

Building text in a loop

Growing a String piece by piece is how you build text whose shape depends on data. Here's a progress bar:

fn main() {
    let done = 3;
    let total = 8;
    let mut bar = String::new();
    for i in 0..total {
        if i < done {
            bar.push('#');
        } else {
            bar.push('.');
        }
    }
    println!("[{bar}] {done}/{total}");
}

[###.....] 3/8

A String reserves extra room as it grows, so pushing many small pieces is cheap. You don't need to know the final length in advance.

Common mistakes

  • Giving push a string. push takes exactly one char, in single quotes:
fn main() {
    let mut s = String::from("hi");
    s.push("!");
    println!("{s}");
}

error[E0308]: mismatched types

The message says expected `char`, found `&str` and suggests '!'. Use s.push('!') for one character or s.push_str("!") for text.

  • Forgetting mut: error E0596, cannot borrow `s` as mutable, as it is not declared as mutable, with a help: line showing where to add mut.
  • Pushing onto a literal. A &str can't grow: let s = "hi"; s.push_str("!"); gives no method named `push_str` found for reference `&str` . Make a String first: let mut s = String::from("hi");
