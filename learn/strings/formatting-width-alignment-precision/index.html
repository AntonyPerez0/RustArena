Formatting: width, alignment, precision

Inside {} you can add a format spec after a colon: {:>8}, {:.2}, {:08.3}. It controls width, alignment, padding, precision, sign and number base. It works the same in println!, format!, write! and panic!.

fn main() {
    let rows = [("Crab plush", 4, 12.5), ("Rust mug", 12, 9.99), ("Sticker", 150, 0.5)];
    println!("{:<12}|{:>5}|{:>8}", "item", "qty", "price");
    println!("{}", "-".repeat(27));
    for (name, qty, price) in rows {
        println!("{:<12}|{:>5}|{:>8.2}", name, qty, price);
    }
}

item        |  qty|   price
---------------------------
Crab plush  |    4|   12.50
Rust mug    |   12|    9.99
Sticker     |  150|    0.50
  • {:<12} pads to width 12, aligned left; {:>5} aligns right; {:^9} centers.
  • {:>8.2} combines width 8 with precision 2 (two decimals).
  • Without an alignment, text is left-aligned and numbers right-aligned.
  • The width is a minimum: a longer value is printed in full, never cut.

The rest of the toolbox

fn main() {
    println!("[{:^9}]", "crab");
    println!("[{:*<8}]", "ok");
    println!("[{:05}]", 42);
    println!("[{:+}] [{:+}]", 7, -7);
    println!("{:x} {:X} {:#x} {:o}", 255, 255, 255, 8);
    println!("{:b} {:#010b}", 5, 5);
    let width = 8;
    println!("[{:>width$.2}]", 3.14159);
    let name = "ana";
    println!("[{name:>6}] [{:.3}]", "crabby");
}

[  crab   ]
[ok******]
[00042]
[+7] [-7]
ff FF 0xff 10
101 0b00000101
[    3.14]
[   ana] [cra]
Spec Meaning
{:*<8} fill character * (any char), then alignment and width
{:05} pad a number with zeros to width 5
{:+} always show the sign
{:x} {:X} {:o} {:b} hexadecimal (lower/upper), octal, binary
{:#x} {:#b} with the 0x / 0b prefix (the prefix counts toward the width)
{:>width$} width taken from a variable named width
{name:>6} inline argument with a spec
{:.3} on text at most 3 characters: the one way to cut text in a format

Width counts chars, not bytes, so é takes one column. (Emoji and CJK characters often take two columns on screen, which format! can't know about.)

Common mistakes

  • {:2} versus {:.2}. The first is a width of 2; the second is 2 decimals.
  • Expecting a narrow width to truncate. {:3} on "crabby" prints all six letters. Use {:.3} to cut.
  • Money in floats. 0.1 + 0.2 isn't exactly 0.3 in binary floating point. Formatting with {:.2} hides it on screen, but real billing code stores whole cents in integers.
