Your first program

A program is a list of instructions the computer follows from top to bottom. Rust is a compiled language: you write the instructions as text (the source code), the Rust compiler (rustc) checks them very carefully and translates them into machine code, and then the program runs. Every time you press Check, a real Rust compiler builds and runs your code.

The shape of every Rust program

fn main() {
    println!("Hi!");
}

Hi!

Piece by piece:

  • fn main() starts a function called main. fn is short for function. Every Rust program begins running at main, no matter how big it is. The empty () say it takes no inputs.
  • The curly braces { } hold the function's body: the instructions that run, in order.
  • println!("Hi!"); prints the text Hi! and then ends the line ("print line"). The text goes inside double quotes.
  • The ! means println! is a macro, not a normal function. Macros are Rust code that writes more code for you; you'll meet several (println!, format!, vec!). For now: printing needs the !.
  • The ; ends the statement, like a period ends a sentence.

Common mistakes

  • Forgetting the !: println("Hi") makes the compiler say cannot find function `println` in this scope. It's a macro, so it's println!.
  • Spelling and capitals matter: Println! or printline! don't exist.
  • Single quotes: 'Hi' is wrong. Text always goes in double quotes; single quotes are for one character, like 'a'.
