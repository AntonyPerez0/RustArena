Capturing variables from the scope

Here is what makes closures more than short functions: a closure can use the variables of the scope it's written in. The closure captures them.

fn main() {
    let tax_rate = 0.25;
    let with_tax = |price: f64| price * (1.0 + tax_rate);

    println!("{:.2}", with_tax(8.0));
    println!("{:.2}", with_tax(20.0));
    println!("rate is still {tax_rate}");
}

10.00
25.00
rate is still 0.25

with_tax uses tax_rate without taking it as a parameter. A fn can't do that, even one written inside main:

fn main() {
    let tax_rate = 0.25;
    fn with_tax(price: f64) -> f64 {
        price * (1.0 + tax_rate)
    }
    println!("{:.2}", with_tax(8.0));
}

error[E0434]: can't capture dynamic environment in a fn item

The compiler even suggests the fix: help: use the `|| { ... }` closure form instead.

Three ways to capture

The compiler looks at what the body does with each variable and captures it in the gentlest way that works:

The body... The closure captures Like writing
only reads x a shared borrow &x
changes x a mutable borrow &mut x
takes ownership of x (moves it somewhere) the value itself a move of x

All the borrowing rules you know apply, with the closure as the borrower. A closure that changes a captured variable must itself be declared mut, because calling it changes something:

fn main() {
    let mut count = 0;
    let mut tick = || count += 1;

    tick();
    tick();
    tick();
    println!("ticks: {count}");
}

ticks: 3

The mutable borrow of count starts where tick is created and lasts until the last call of tick. After that, count is free again, so the println! is fine.

Common mistakes

  • Forgetting mut on the closure. Calling a closure that changes what it captured needs mutable access to the closure:
fn main() {
    let mut count = 0;
    let tick = || count += 1;
    tick();
    println!("{count}");
}

error[E0596]: cannot borrow `tick` as mutable, as it is not declared as mutable
  • Using the variable while the closure still borrows it. Between creating tick and its last call, count is mutably borrowed, so you can't even read it:
fn main() {
    let mut count = 0;
    let mut tick = || count += 1;
    tick();
    println!("{count}");
    tick();
}

error[E0502]: cannot borrow `count` as immutable because it is also borrowed as mutable

Fix it by finishing with the closure first, or by passing the value in as a parameter instead of capturing it.
