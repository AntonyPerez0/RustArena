Integer division and remainder

In the first module you saw that 7 / 2 is 3. When both sides are integers, / is integer division: it divides and throws away the fractional part. The % operator (remainder, often called "modulo") gives what was left over:

fn main() {
    println!("{} {}", 7 / 2, 7 % 2);
    println!("{} {}", 17 / 5, 17 % 5);
    println!("{} {}", -7 / 2, -7 % 2);
}

3 1
3 2
-3 -1

Integer division truncates toward zero: -7 / 2 is -3, not -4. The remainder takes the sign of the left side, so -7 % 2 is -1.

Why this is useful

Integer division and remainder split a quantity into units:

fn main() {
    let total_minutes = 135;
    let hours = total_minutes / 60;
    let minutes = total_minutes % 60;
    println!("{total_minutes} min = {hours} h {minutes} min");

    let n = 1234;
    println!("last digit: {}", n % 10);
    println!("without it: {}", n / 10);
}

135 min = 2 h 15 min
last digit: 4
without it: 123

Patterns you'll use again and again:

  • n % 2 is 0 for even numbers and 1 for odd (positive) numbers.
  • n % 10 is the last digit of n, and n / 10 removes it.
  • For positive n, n % k is always between 0 and k - 1, which is how things wrap around: hours on a clock, whose turn it is in a game.

Workplace note: for unsigned types (u8, u32, u64, ...), Rust also has n.is_multiple_of(k), which reads like the question it asks and doesn't panic when k is 0. Recent clippy versions suggest it over n % k == 0 (lint manual_is_multiple_of). This course mostly writes % k == 0, because it works for every integer type, signed ones included.

Dividing by zero

Integer division by zero has no answer, so Rust stops the program with a panic (a deliberate crash with a message), attempt to divide by zero. When the compiler can already see the zero, it refuses to compile instead (error: this operation will panic at runtime). Floats behave differently, as you'll see.

Common mistakes

  • Expecting a fraction: let average = 7 / 2; is 3. For 3.5 you need floats (two steps from now).
  • Order of operations: *, / and % happen before + and -, as in math, so 2 + 3 * 4 is 14. Add parentheses when in doubt: (2 + 3) * 4.
