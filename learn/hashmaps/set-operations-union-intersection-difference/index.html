Set operations: union, intersection, difference

Sets can be combined the way you did with Venn diagrams at school. Who came on both days? Who came at all? Which required skills is a candidate missing?

use std::collections::BTreeSet;

fn main() {
    let monday = BTreeSet::from(["ana", "bo", "cy", "dee"]);
    let tuesday = BTreeSet::from(["bo", "dee", "eli"]);

    println!("both days: {:?}", &monday & &tuesday);
    println!("either day: {:?}", &monday | &tuesday);
    println!("only monday: {:?}", &monday - &tuesday);
    println!("exactly one day: {:?}", &monday ^ &tuesday);

    for name in monday.intersection(&tuesday) {
        println!("{name} came twice");
    }
    println!("{}", tuesday.is_subset(&monday));
}

both days: {"bo", "dee"}
either day: {"ana", "bo", "cy", "dee", "eli"}
only monday: {"ana", "cy"}
exactly one day: {"ana", "cy", "eli"}
bo came twice
dee came twice
false

  • BTreeSet::from([...]) builds a set from an array in one go (HashSet::from, HashMap::from([(k, v), ...]) and BTreeMap::from work the same way).

  • The operators build a new set from two borrowed ones:

    Operator Method Elements in the result
    &a & &b a.intersection(&b) in both
    &a | &b a.union(&b) in either
    &a - &b a.difference(&b) in a but not in b
    &a ^ &b a.symmetric_difference(&b) in exactly one of them

  • The methods don't build a set; they give you the elements one by one, ready for a for loop. Each element comes as a reference (&&str here, &String for a set of Strings): clone it if you need an owned copy.

  • is_subset, is_superset and is_disjoint (no elements in common) answer yes/no questions.

The same operators and methods work on HashSet. The results are HashSets too, so sort them before printing.

Common mistakes

  • Forgetting the &s. The operators take the sets by reference:

    use std::collections::BTreeSet;

fn main() {
    let a = BTreeSet::from([1, 2]);
    let b = BTreeSet::from([2, 3]);
    let c = a & b;
    println!("{:?}", c);
}

    error[E0369]: no implementation for `BTreeSet<{integer}> & BTreeSet<{integer}>`

    Write &a & &b.

  • Mixing up the direction of -. &a - &b is "a without b"; &b - &a is a different set.
